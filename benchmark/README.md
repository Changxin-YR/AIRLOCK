# 合成一致性评测，不是外部安全排行榜

200 个合成实例，20 个场景家族，120 dev / 80 test。样本来自声明的资源与策略契约，不是真实事故日志、真实用户流量或独立双人标注。固定的家族划分用于检验数据泄漏防线，不构成未知攻击泛化能力的证明。重叠的业务概念仍可能跨家族出现。

`generate.py` 生成案例和 SHA-256 manifest；`evaluate.py` 校验 manifest 后运行。生产策略不能通过评测程序修改。首次编写时已知道策略目标，因此不把 test 称为盲测。修改案例必须重新生成并审阅版本差异。

参考效果由独立的纯 Python 条件匹配及字典变更计算；不调用生产代码的预检、执行或 diff 函数。每次预检检查目标文件完整摘要不变，比较全部主键与字段变化，而不只比较行数。

对照的 static_conservative 在同一权限检查后让读请求通过、写请求全部进入审批，只在离线评分中运行；运行系统不允许绕过预检。不把它叫“行业竞品”。模型消融没有真实凭据，结果写 NOT_TESTABLE，而不是填造漂亮数字。

报告包含三态混淆矩阵、危险直接放行（给出分子分母）、误报、禁止误转审批、预检覆盖率、参考效果一致性和当前环境的 p50/p95。未授权与无效请求在覆盖率分母内。这里测量的是顺序本地预检，不是包含人工等待的端到端吞吐。

```bash
python benchmark/evaluate.py --split all --output Evidence/local/benchmark.json
```

没有开展真实用户实验，没有 Cohen's κ、审批耗时改善或外部采用数据。
