# 从零重建计划

基线：2026-09-30。仓库沿用 AIRLOCK，产品描述为 Agent Change Review。维护者授权替换当前全部文件；不重写历史，不修改其他仓库。

## 范围
Vue 3 + TypeScript + Vite + Pinia + Element Plus；FastAPI + Pydantic + SQLAlchemy；独立 SQLite 元数据与受控目标；官方 MCP SDK 1.x 维护线。先验证实际兼容版本，再提交锁文件。

只有一个注册的演示 CRM 资源，结构化 query/update/delete，字段与条件白名单，服务端注入项目范围。拒绝原始 SQL、Shell、未知 Schema、未知触发器、外部函数和超限预检。小数据集范围内比较全部受管表的主键级前后差异，包含已知级联。

## 安全边界
Agent 只持有提交/查询自己操作的凭据；审批者使用独立会话；执行器单独持有目标库。网关与执行器通过私有凭据及签名执行许可连接。容器部署中 Agent 不挂载目标卷和网关秘密。宿主机管理员或审批浏览器完全失陷不在保证范围。

## 阶段与验收
P0 环境与契约；P1 最小闭环；P2 失败语义；P3 浏览器产品；P4 外部协议/模型；P5 独立验收。每阶段运行真实测试，提交修改和证据。未经实际运行的模型、容器及用户实验均不得标绿。

## 重要取舍
使用全受管业务状态摘要，接受无关写入导致 STALE；等待人时不持有目标锁。只有在目标事务内取得回执才能认为执行成功。审批不改变参数；改动创建新操作。没有 Redis、Celery、多租户管理、任意代理、RAG 或自学习放行。

## 执行环境
本地工具容器目前无法解析公网地址。优先在本地验证现有 Python 依赖与真实 SQLite；通过仓库 CI 获取并验证缺失的公开依赖，不把缺依赖标成代码通过。
