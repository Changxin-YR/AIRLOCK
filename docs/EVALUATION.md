# 评测方法：结果、分母与局限

当前新增管线：`benchmark/research.py` 验证多来源 schema、分组隔离、双人标签/κ、分歧与真人配对统计；`benchmark/ablation.py` 固定四组并将未授权模型组记为 BLOCKED_EXTERNAL；`scripts/measure_latency.py` 对同一目标随机交替直接 SQLite 与真实 HTTP 放行，报告逐对增量、均值及 p95。`/assets/study.html` 提供匿名同意、任务导入、A/B 交叉分配、可见时长和导出；automation 不计真人。运行方法和局限见 [运行手册](OPERATIONS.md)。本文旧合成分数仅为历史回归背景，最终提交与新证据以 [验收矩阵](acceptance/COMPLETION_MATRIX.md) 为准。

本轮预注册：T3 静态分类 p95 <300 ms、T4 克隆/执行/差异 p95 <5000 ms，另列 HTTP 端到端；T6 使用同负载逐对 `(proxy-direct)` 的 p95 <100 ms，另报均值，不能相减无关 p95。并发 1、1206 行、10 次热身、60 读配对/30 写样本、seed2073；不外推真实模型或生产并发。所有原始样本保留，慢样本不剔除。H1/H2/H3/H4/H5 没有真人/真实工作日数据时都是未验证。

## 回归数据不是人类实验

benchmark/generate.py 确定性生成200条样例，来自40个模板族、每族5个相关变体。来源全部标为 synthetic_authored_policy_case，标签是作者预置的当前策略期望，不是假扮真实事故、生产日志或专家金标。

按模板族拆分：dev120条/24族，test80条/16族；同族不会跨集合。作者知道所有模板，仍有构造偏差；80条变体不能视为80个独立真实样本。tuning模式禁止读取test只是流程防误用，不是对恶意作者的访问控制。冻结哈希为243854b51e7039324de4c31fa7a67af1a98ddc48b9c9edfbbac581a2c2f73af7，不得根据test失败随意改标签。

## 指标口径

三态准确率：预测与预置 pass/need_approval/block 相同的比例。策略拦截召回：期望非pass中预测非pass的比例。这个召回包含无效/不支持语句，不能称现实危险操作召回。

支持只读误报率：期望pass却被阻断/送审，占所有期望pass样例。支持写入拦截率：期望need_approval中未被直接放行的比例。后者不能识别把所有可审批操作永久block造成的可用性损失，所以必须同时报告三态混淆矩阵。

影响计数：支持预演的写入changed_rows与构造时已知变化数一致的数量及分母。每例独立初始化合成库；前后状态不会跨样例污染。

独立基线是另写的朴素关键词过滤器，不是关掉Airlock功能，更不是某个真实竞品。纯 LLM 和混合 LLM 已在本轮授权下运行，结果见下文；真人 A/B 仍未运行。四臂的纯 LLM 建议只用于评测，不能授予实际写入权限。

## 已有测试集结果

测试集标签为30个pass、20个need_approval、30个block。

| 指标 | 关键词基线 | Airlock |
|---|---:|---:|
| 三态一致 | 60/80 | 80/80 |
| 策略拦截召回 | 40/50 | 50/50 |
| 支持只读误报 | 0/30 | 0/30 |
| 支持写入被拦截 | 20/20 | 20/20 |
| 变化行数与期望一致 | 未实现 | 20/20 |

关键词基线在一些指标上与Airlock相同，这个结果必须保留。Airlock在此合成集上的100%不支持“真实世界100%安全”“优于所有模型/竞品”等结论。最新运行的全量逐样例输出见CI的benchmark-test.json和对应source.zip。

内部评估、编译与预演有独立计时。内部评估不包含最终持久化/提交、HTTP或人等待，因此不能拿它直接宣称端到端放行额外延迟低于100ms。报告机器、依赖版本、样例分母和原始值，不只报漂亮百分比。

## 程序、协议与部署验收

pytest涵盖身份伪造、绑定、幂等并发、数据漂移、到期、进程退出和审计失败。独立stdio客户端及官方MCP Python SDK分别检验协议/HTTP闭环，不把协议测试等同真实模型行为。

Playwright原生浏览器检验真实页面的登录、拒绝保留1206行、批准修改、SSE、范围确认、审计、退出和移动布局。新回归包括105条新只读记录不能挤掉待审批项。--bridge是历史环境受限时的替代DOM测试，不可代替native。

Docker脚本在唯一临时Compose项目验证：非root/只读根/无额外能力、Agent无服务器数据卷及审核密钥、不能伪造审批或读取控制表、审批后效果与审计重启持久、服务端入口与内部网络分离。它不是通用容器逃逸测试，也不是多人真实审批实验。

验收同时检查命令exit_code、必需JUnit测试未跳过、原生报告、Docker报告及数据值。第二轮CI曾因tee丢失退出码而假绿；已保留失败历史并增加run_logged回归。产物哈希只能证明文件一致，不能独自证明功能通过。

## 真人实验协议（未执行，n=0）

假设：影响优先界面改善理解与决策，而不只是更快点击。任务必须包含业务授权、允许范围、数据变更意图与恢复限制；仅看SQL行数不存在可靠的批准金标。

取得参与者知情同意，以去标识ID记录。A使用普通确认信息，B使用Airlock；采用难度匹配任务和顺序交叉平衡，避免重复相同题目的记忆效应。先练习再测量，由独立评审建立授权金标并记录分歧。

记录前台可见时长、批准/拒绝、正确性、理解题与主观负担。客户端visible_ms只作不可信实验遥测，不参与授权。报告中位数、尾部、准确性和不确定性；<1秒只是复核信号，不等同橡皮图章。便利小样本不能外推全行业。

## 2026-10-02 真实 DeepSeek 四臂结果

授权模型为 DeepSeek-V4.1-Flash，固定官方 Responses 接口、非思考模式。三个模型臂各调用200个冻结合成样例，共600次；关键词臂独立实现且不调用模型。dev120/test80分开报告，保留原v1提示及逐例行。所有臂只做无副作用评测，纯LLM建议不能成为服务端授权。

| 臂 | dev三态一致 | test三态一致 | dev/test有效模型输出 | dev支持只读额外送审/阻断 | test支持只读额外送审/阻断 |
|---|---:|---:|---:|---:|---:|
| keyword | 70/120 | 60/80 | 不适用 | 15/30 | 0/30 |
| pure_llm | 54/120 | 50/80 | 119/120，80/80 | 11/30 | 0/30 |
| hybrid_no_preview | 99/120 | 80/80 | 119/120，80/80 | 10/30 | 0/30 |
| hybrid_with_preview | 102/120 | 76/80 | 112/120，76/80 | 10/30 | 0/30 |

这是作者合成策略三态一致率，**不是独立危险语义召回**。dev有明显额外送审，test中带预演臂低于不带预演臂，不能选取最好结果声称预演总能提高准确率。原始14次schema异常保留为失败并计入总体指标；报告另含有效provider子集分母。纯LLM对禁止操作给pass的预测只存在于实验记录，没有执行通道。

开发集10个失败样例重放时，v1复现2次reason超过严格800字符上限，原输出/schema_errors已记录；其余8次有效，不能推断最初14次全部同因。v2增加“简短理由≤300字符”指令，严格schema不放宽，开发重放10/10有效。原600次结果未覆盖；没有根据测试集结果改标签或声称全量v2消融通过。

所有模型相关实验共638次调用，622有效/16无效；同一持久账本的保守占用¥1.11779816（预算合计¥3），已知有效usage估价¥0.84922816。失败保留预占，缓存读token与应用结果缓存分开。官方高峰价估算不等于账单实扣。原始输出、逐次hash/ID/usage/耗时、账本和真实退出码见 evidence/continuation-20261002/。
